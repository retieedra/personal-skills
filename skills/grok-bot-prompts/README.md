# Grok bot prompts

Turn workflow ideas and meeting notes into copy-ready Grok bot prompts. Start with context-building and voice learning, then define recurring steps and explicit approval boundaries.

## Install

```bash
npx skills add https://github.com/retieedra/personal-skills --skill grok-bot-prompts
```

## Use

Ask your agent:

> Use grok-bot-prompts to turn these meeting notes into a post-call follow-up bot prompt. Learn my voice first, save email drafts, and ask for approval in Slack before sending.

The skill writes prompts; running it does not deploy a bot or activate a scheduler.
