# Authoring sources

Reviewed 26 October 2026. These are technical documentation and design guidance, not controlled evidence that this particular skill improves results.

- [Agent Skills specification](https://agentskills.io/specification): required name and description, directory naming, optional references, and progressive loading. Applied here through a concise entry point with conditional references.
- [Best practices for skill creators](https://agentskills.io/skill-creation/best-practices): derive procedures from real work and corrections, add knowledge the agent lacks, and refine from execution. Applied here by preferring observed patterns over speculative skill collections.
- [Evaluating skill output quality](https://agentskills.io/skill-creation/evaluating-skills): realistic prompts, boundary cases, observable outcomes, and comparisons against a baseline. Applied here by distinguishing format checks from behavioral evidence.

The local skill-creator guidance informed the authoring process. This package contains original instructions by Reti Eedra rather than a copied third-party skill.

The five-occurrence suggestion threshold, permission to create earlier on explicit request, and preference for plain, connected explanations are editorial choices. They are not universal requirements of the Agent Skills format or experimentally established optimal settings. Natural-language discovery and cross-chat context depend on the host application; this package adds no monitor, scheduler, or persistent memory.
